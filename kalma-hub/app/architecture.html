Kálma Player

Port 12002 — Adaptive Music Companion · 20 JS files · 3 screens

The Player is Kálma's flagship product: a generative music engine that responds to time of day, weather, physical movement, and emotional context in real-time. It creates an endless, evolving soundscape with an introspective base character — never repetitive, always contextual.

Signal Chain

Sources into musicBus (gain 1.0), dry/reverb split, through Compressor (-10dB threshold, ratio 2.5:1, soft knee 20dB, attack 10ms), Warmth EQ (low-shelf +1.5dB @ 200Hz), Air EQ (high-shelf +2.5dB @ 6kHz), to Master output.

Shared

Reverb Engine

4.5-second convolution reverb with physically-modeled early reflections, 45ms pre-delay, and stereo L/R decorrelation for immersive spatial depth.

Shared

AdaptiveEngine

Drone bed with evolving voices (15-35s lifetime), chord pads changing every 25-60s, introspective base character. The sonic foundation of all Kálma music.

Shared

Context Engine

Fuses time of day, weather (Open-Meteo API), season, holidays, and device motion. Blend speed 20% per update for smooth transitions between states.

Player

MusicBrain

200+ emotion patterns with semantic interpretation. Text input weighted at 0.7, movement weight 0.75. Instant pattern matching for real-time responsiveness.

Shared

LLM Mood Engine

Gemini 2.5 Flash Lite via OpenRouter. Generates structured musical parameters from mood text. Rule-based fallback ensures zero-latency operation when API unavailable.

Player

Piano Engine v4

Activated via "piano" in shift mood. Chord-aware note picking (65% chord tones), 45-60 BPM calm tempo. Two-hand Debussy-inspired performance. Drone bed ducks but stays alive.

Shared

Beats Engine

4 beat types: Upbeat, Grounded, Dreamy, Energetic. When Beats Adaptive is enabled, movement triggers beats (walking = dreamy, active = energetic). 4s fade-in. Off by default — user must enable Adaptive toggle or select a beat type manually.

Player

Movement System

DeviceMotion analyzed every 3s (90 samples). Spawns reactive voices with filter sweep fade-in (2-3s) and filter-close fade-out (3s). Physical gesture becomes sound.

Player

Learning Engine

Like/dislike feedback builds per-parameter bias (0-30%). Preference history fed back to LLM context for increasingly personalized compositions over time.

Player

Visualizer

Sacred geometry patterns driven by frequency analysis. Real-time visual feedback synchronized to the audio engine's output.

Player

Sources

Drones/Pads (stereo panned +/-0.35), Piano Engine, VA/FM/WT Synths (gain 0 default), Beats Engine, Movement-reactive Voices, Layers/Ambience.

Kálma Wellness

Port 12001 — Therapeutic Sound App · 22 JS files + Service Worker

Wellness extends the shared engine with therapeutic modalities: binaural beats, isochronic tones, guided meditation, chakra tuning, and ambient radio streams. Built for the spiritual community and mindful living. Architecture wraps the core: app.js → KalmaAudioEngine → EngineMusic → AdaptiveEngine.

Binaural Beats

Precisely tuned frequency differentials between left and right ears for brainwave entrainment. Supports delta, theta, alpha, beta, and gamma states.

Wellness

Isochronic Tones

Single-channel rhythmic pulses that don't require headphones. Evenly spaced tones with distinct on/off patterns for auditory neural stimulation.

Wellness

Meditation Engine

Structured meditation sessions with progressive relaxation, breath timing, and ambient soundscapes that evolve with session depth.

Wellness

Voice Guidance

Custom voice guidance for chakra tuning and meditation. Gentle prompts synchronized with the musical environment.

Wellness

Ambience Engine

Layered environmental soundscapes — rain, forest, ocean, wind. Dynamically mixed with the generative music engine output.

Radio Streams

Chakra Tuning
